```json
{
  "$schema": "https://unpkg.com/@changesets/config@3.0.0/schema.json",
  "changelog": ["@changesets/changelog-github", { "repo": "lokvis/lokvis" }],
  "commit": false,
  "fixed": [],
  "linked": [],
  "access": "public",
  "baseBranch": "dev",
  "updateInternalDependencies": "patch",
  "ignore": ["@lokvis/playground", "@lokvis/docs"]
}
```

| 字段 | 值 | 状态 | 说明 |
|------|----|----|------|
| `changelog` | `@changesets/changelog-github` | ✅ | 自动从 GitHub PR 生成 changelog |
| `commit` | `false` | ✅ | changeset version 不自动 commit（手动 review 后 commit） |
| `fixed` | `[]` | ✅ | 无固定版本组（各包独立升版） |
| `linked` | `[]` | ✅ | 无联动版本组 |
| `access` | `public` | ✅ | 公开发布（与各包 `publishConfig.access` 一致） |
| `baseBranch` | `dev` | ✅ | 主开发分支为 `dev`（与 deploy workflow 一致） |
| `updateInternalDependencies` | `patch` | ✅ | 内部依赖升级时只 bump patch（避免 minor 联动放大） |
| `ignore` | `["@lokvis/playground", "@lokvis/docs"]` | ✅ | playground 和 docs 不发 npm（private 包） |

### Step 5 — 配置 NPM_TOKEN

仓库 `lokvis/lokvis` → Settings → Secrets and variables → Actions → New repository secret：

- `NPM_TOKEN` = npmjs.com Access Token（Automation 类型，权限 Publish）

> npm provenance 已在 release.yml 启用（`NPM_CONFIG_PROVENANCE: 'true'` + `id-token: write`），需 npm 账号开启 2FA 并支持 provenance。

### Step 6 — 触发 release workflow

**方式 A（推荐，tag 触发）**：

```bash
# 在 dev 分支打 tag
git tag v0.2.0-beta.0
git push origin v0.2.0-beta.0
# 自动触发 release.yml，detect-release-channel 检测 tag 在 dev 分支 → channel=beta → dist-tag=beta
```

**方式 B（手动 npm publish）**：

```bash
# 本地登录 npm
npm login

# 逐包发布（pre 模式不能用 changeset publish --tag）
pnpm -r --filter '@lokvis/*' exec npm publish --tag beta --access public
```

release.yml 的发布逻辑（L98-124）：
- 检测 `.changeset/pre.json` 存在 → 走 pre 模式分支
- 遍历 `packages/*/`，跳过 `private: true` 的包
- 对每个包执行 `npm publish --registry https://registry.npmjs.org --tag beta --access public --provenance`
- 已发布的版本（npm view 返回相同 version）自动跳过

### Step 7 — 验证发布成功

```bash

$ npm install @lokvis/sdk@0.2.0-beta.0
$ node -e "import('@lokvis/sdk').then(m => console.log(Object.keys(m)))"
```
