## 一、商业模式总览

### 1.1 收入结构（理想状态）

| 收入来源 | 占比 | 模式 | 启动时间 |
|---------|------|------|---------|
| **Workflow / Plugin Marketplace** | 35% | 抽成（30%） | Year 2 |
| **企业授权（Enterprise）** | 25% | 年费/一次性 | Year 2 |
| **Cloud Pro / Sync** | 15% | 订阅 $5-15/月 | Year 1 |
| **Affiliate（Context Commerce）** | 15% | CPA 分成 | Year 1 |
| **一次性专业包** | 10% | $29-79 一次性 | Year 1 |

### 1.2 商业化时间线

```
Month 0-6:   免费 MVP，积累用户
Month 6-12:  推出 Pro 一次性购买 + Affiliate
Month 12-18: 推出 Cloud Pro 订阅 + 企业版
Month 18-24: Marketplace 上线，开放 UGC
Month 24+:   生态成熟，多元收入平衡
```

## 二、分层定价策略

### 2.1 免费层（Free）

| 项目 | 说明 |
|------|------|
| **价格** | $0 |
| **目标** | 获取用户、口碑传播、SEO 流量 |
| **功能** | 基础工具 + 浏览器运行 + 离线可用 + 无需登录 |
| **限制** | 工作流保存上限 5 个，无批处理，无高级预设 |
| **策略** | 无限制使用核心功能，仅限制"效率增强"能力 |

### 2.2 Pro 层（一次性购买）

| 项目 | 说明 |
|------|------|
| **价格** | **$49 一次性**（早鸟 $29） |
| **目标** | 专业用户、低频但长期使用者 |
| **功能** | 无限工作流 + 批处理 + 高级预设 + 本地 AI 模型 + 更多导出格式 |
| **限制** | 单设备授权，无云同步 |
| **策略** | 一次性付费降低决策门槛，专业用户更易接受 |

### 2.3 Cloud Pro 层（订阅）

| 项目 | 说明 |
|------|------|
| **价格** | **$9/月** 或 **$79/年**（年付优惠 27%） |
| **目标** | 高频用户、多设备用户、团队协作 |
| **功能** | Pro 所有功能 + 云同步 + 多设备 + 团队共享 + 优先支持 |
| **限制** | 按席位计费 |
| **策略** | 强调"便利"而非"计算资源"，与 Local-first 理念一致 |

### 2.4 企业层（Enterprise）

| 项目 | 说明 |
|------|------|
| **价格** | **$1000-50000+/年**（按规模） |
| **目标** | 法律/医疗/金融/政府/电商团队 |
| **功能** | 私有部署 + 白标 + SDK 授权 + SSO + SLA + 审计日志 |
| **限制** | 按合同定制 |
| **策略** | 客单价最高，主打隐私合规 + 集成能力 |

### 2.5 定价对比表

| 计划 | 价格 | vs iLovePDF | vs Smallpdf | 价值点 |
|------|------|------------|-------------|--------|
| Free | $0 | 相当 | 相当 | 本地处理 + 工作流 |
| Pro | $49 一次性 | $4/月 × 12 = $48 | $11/月 × 12 = $132 | **一次付费，永久使用** |
| Cloud Pro | $79/年 | $4/月 × 12 = $48 | $11/月 × 12 = $132 | 多设备 + 团队 + 同步 |
| Enterprise | $1000+/年 | Business 定制 | Team $65/月/席 | **私有部署 + 合规** |

**核心优势**：Pro 一次性 $49 对比 Smallpdf 年费 $132，**节省 63%**，且永久使用。

## 三、Workflow Marketplace 设计

### 3.1 市场分层

| 层级 | 内容 | 价格 | 抽成 |
|------|------|------|------|
| **Workflow** | 单个工作流（如 Shopify Images） | $3-15 | 30% |
| **Template** | 配置模板（如 Instagram Post 1080x1350） | $1-5 | 30% |
| **Preset Pack** | 预设包（如 Social Media Pack 6 合 1） | $9-19 | 30% |
| **Workspace** | 整套工作台（如 Podcast Workspace） | $29-49 | 30% |
| **Plugin** | 第三方插件 | $0-99 | 30% |

### 3.2 售卖模式

#### 模式一：一次性购买

```
Podcast Workflow → $8 → 永久使用 + 1 年更新
```

#### 模式二：Bundle 打包

```
Creator Bundle（39 个 Workflow）→ $19 → 节省 75%
```

#### 模式三：Creator Subscription

```
每月新增 20 个 Workflow + 模板 + Preset → $5/月
```

#### 模式四：Creator Store（创作者自营）

```
John 的 100 个 Workflow → 自定价 → 平台抽 30%
```

### 3.3 防复制策略

单纯 JSON 配置容易被复制，因此 Workflow 售卖的是**持续维护的解决方案**：

| 附加值 | 说明 |
|--------|------|
| 版本历史 | 持续更新，兼容最新 Runtime |
| 更新日志 | 透明化改进 |
| 自动升级 | 一键升级到新版本 |
| 评论评分 | 社区口碑 |
| 作者信誉 | 认证创作者 |
| 下载量 | 社会证明 |
| 官方认证 | 信任背书 |
| 配套文档 | 最佳实践 |
| AI 参数优化 | 根据输入自动调整 |

### 3.4 AI 生成 Workflow（未来方向）

```
用户："帮我把这批商品图处理成 Shopify 要求的格式"
    ↓
AI 生成 Workflow JSON
    ↓
用户验证满意 → Save
    ↓
可选：Publish to Marketplace
    ↓
平台抽取 30% 佣金
```

**生态飞轮**：AI 生成 → 用户验证 → 社区沉淀 → 更多真实工作流 → AI 学习 → 更好生成。

## 四、Context Commerce（场景化商业推荐）

### 4.1 核心理念

> **不是 Banner 广告，而是工作流末端的自然推荐。**

传统广告联盟：
```
页面 → Banner → 点击 → 收入
```

Lokvis Context Commerce：
```
用户任务 → Workflow → 完成任务 → 推荐下一步需要的服务 → Affiliate 收入
```

### 4.2 推荐场景

#### 场景一：Export Destination

```
用户完成 PDF 处理
    ↓
推荐：Open in Canva / Google Drive / Dropbox / Notion
    ↓
Affiliate 收入
```

#### 场景二：Workflow Recommendation

```
用户运行 "Publish Podcast" 工作流
    ↓
推荐：Buzzsprout / Transistor / Captivate（托管平台）
    ↓
Affiliate 收入（通常 $25-100/注册）
```

#### 场景三：Creator Toolkit

```
用户访问 "How to Start a Podcast" 指南
    ↓
推荐：麦克风 / 托管 / 编辑软件 / AI 工具
    ↓
Affiliate 收入
```

#### 场景四：AI Workflow

```
用户运行 "Generate Subtitle → Translate → Voice Clone"
    ↓
推荐：ElevenLabs / HeyGen / Runway
    ↓
Affiliate 收入（通常 20-30%分成）
```

### 4.3 高价值 Affiliate 机会

| 类别 | 推荐对象 | 单次佣金 |
|------|---------|---------|
| 电商 | Shopify, Amazon Seller Tools | $50-200 |
| 播客 | Buzzsprout, Transistor | $25-100 |
| AI 工具 | ElevenLabs, HeyGen, Runway | $20-50 |
| 开发者 | Cloudflare, Vercel, Railway | $10-25 |
| 设计 | Figma, Icons, Fonts | $5-20 |
| 视频 | YouTube Premium, Vimeo | $5-15 |

### 4.4 Workflow Commerce（进阶）

```
Shopify Images Workflow
    ↓
推荐：Shopify Themes / SEO Tools / Email Tools
    ↓
平台 + 创作者双重 Affiliate 收入
```

**收入双层结构**：Workflow Sale + Affiliate Commission。

## 七、Open Core 商业化策略

### 7.1 开源 vs 闭源边界

#### 开源（MIT）

| 模块 | 开源原因 |
|------|---------|
| Schema | 生态标准，越多人依赖越好 |
| Runtime | 核心引擎，社区贡献 |
| SDK | 开发者采用 |
| Plugin SDK | 插件生态 |
| CLI | 自动化场景 |
| Engine Adapters | 可替换性 |

#### 闭源（商业）

| 模块 | 闭源原因 |
|------|---------|
| Marketplace | 商业核心 |
| Cloud Sync | 增值服务 |
| Billing | 支付逻辑 |
| Team Collaboration | 企业功能 |
| Analytics | 商业智能 |
| AI Service | API 成本 |
| Enterprise Features | 高客单价 |

### 7.2 开源商业化的成功参照

| 公司 | 开源 | 商业化 | 估值/收入 |
|------|------|--------|----------|
| VS Code | 编辑器 | Azure 集成 | 微软旗下 |
| GitLab | CE | EE + Cloud | $60 亿估值 |
| Supabase | 客户端 | Cloud | $20 亿估值 |
| n8n | Fair-code | Cloud + Enterprise | 5500 万欧 B 轮 |
| Strapi | MIT | Cloud + Enterprise | $4400 万 A 轮 |

**启示**：开源核心 + 商业云服务是验证过的模式。Lokvis 的独特之处在于**本地优先**使云服务成本极低。

### 7.3 双产品策略

#### 产品 A：开源平台

| 维度 | 说明 |
|------|------|
| 目标用户 | 开发者、AI Agent、第三方产品、插件作者 |
| 核心价值 | 成为 Browser Workflow Runtime 事实标准 |
| 成功指标 | GitHub Stars、npm 下载量、第三方插件数、Schema 引用次数 |

#### 产品 B：商业产品

| 维度 | 说明 |
|------|------|
| 目标用户 | 内容创作者、电商卖家、设计师、企业团队 |
| 核心价值 | 最好用的 Browser Workspace |
| 成功指标 | PWA 安装量、Marketplace GMV、Pro 用户数、企业客户数 |

**共享 Runtime，不同增长方式**。

## 八、商业化风险与应对

### 8.1 主要风险

| 风险 | 概率 | 应对 |
|------|------|------|
| Marketplace 冷启动失败 | 高 | 官方先建 1000+ Workflow |
| 用户不愿为 Workflow 付费 | 中 | 强化"持续维护"价值，而非单次配置 |
| 企业销售周期长 | 高 | 第三年才重点投入 |
| Affiliate 收入波动 | 中 | 多元化推荐对象 |
| 开源版本被白嫖 | 低 | 商业价值在 Marketplace/Cloud，非 Runtime |

### 8.2 不推荐的商业模式

| 模式 | 原因 |
|------|------|
| 展示广告（AdSense） | 破坏 PWA 体验，品牌掉价 |
| API 按调用收费 | 违背 Local-first 理念 |
| 强制订阅才能使用 | 降低用户获取效率 |
| 数据售卖 | 违背隐私承诺，法律风险 |
| 流量导流（SEO 租金） | 短期收入，长期损害品牌 |
