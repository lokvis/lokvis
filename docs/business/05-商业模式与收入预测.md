## 一、商业模式总览

### 1.1 收入结构（理想状态）

| 收入来源 | 占比 | 模式 | 启动时间 |
|---------|------|------|---------|
| **Cloud Pro 订阅** | 40% | $9/月 或 $79/年 | Year 1 |
| **一次性专业包（Pro）** | 30% | $49 一次性 | Year 1 |
| **企业授权（Enterprise）** | 20% | 年费/一次性 | Year 2 |
| **Affiliate（Context Commerce）** | 10% | CPA 分成 | Year 1 |

> **v2.0 变更**：原 v1.0 将"Workflow / Plugin Marketplace 佣金"列为核心收入（35%），因 AI 生态冲击（Claude Skills Directory 上线、MCP 成为事实标准）已取消该模式，改为**免费社区分享**。详见第十章"与 AI 调整方案一致性"。

### 1.2 商业化时间线

```
Month 0-6:   免费 MVP，积累用户
Month 6-12:  推出 Pro 一次性购买 + Cloud Pro 订阅 + Affiliate
Month 12-18: 企业版上线 + Cloud Pro 功能扩展
Month 18-24: 社区分享生态成熟 + MCP Server 发布
Month 24+:   多元收入平衡，Cloud Pro 为 recurring 收入主力
```

## 二、分层定价策略

### 2.1 免费层（Free）

| 项目 | 说明 |
|------|------|
| **价格** | $0 |
| **目标** | 获取用户、口碑传播、SEO 流量 |
| **功能** | 基础工具 + 浏览器运行 + 离线可用 + 无需登录 + 社区分享的 workflow |
| **限制** | 工作流保存上限 5 个，无批处理，无高级预设 |
| **策略** | 无限制使用核心功能，仅限制"效率增强"能力 |

### 2.2 Pro 层（一次性购买）

| 项目 | 说明 |
|------|------|
| **价格** | **$49 一次性**（早鸟 $29） |
| **目标** | 专业用户、低频但长期使用者 |
| **功能** | 无限工作流 + 批处理 + 高级预设 + 本地 AI 模型 + 更多导出格式 |
| **限制** | 单设备授权，无云同步 |
| **策略** | 一次性付费降低决策门槛，专业用户更易接受 |

### 2.3 Cloud Pro 层（订阅）

| 项目 | 说明 |
|------|------|
| **价格** | **$9/月** 或 **$79/年**（年付优惠 27%） |
| **目标** | 高频用户、多设备用户、团队协作 |
| **功能** | Pro 所有功能 + 云同步 + 多设备 + 团队共享 + 优先支持 + AI Credits |
| **限制** | 按席位计费 |
| **策略** | **核心 recurring 收入来源**，强调"便利"而非"计算资源"，与 Local-first 理念一致 |

### 2.4 企业层（Enterprise）

| 项目 | 说明 |
|------|------|
| **价格** | **$1000-50000+/年**（按规模） |
| **目标** | 法律/医疗/金融/政府/电商团队 |
| **功能** | 私有部署 + 白标 + SDK 授权 + SSO + SLA + 审计日志 |
| **限制** | 按合同定制 |
| **策略** | 客单价最高，主打隐私合规 + 集成能力 |

### 2.5 定价对比表

| 计划 | 价格 | vs iLovePDF | vs Smallpdf | 价值点 |
|------|------|------------|-------------|--------|
| Free | $0 | 相当 | 相当 | 本地处理 + 工作流 |
| Pro | $49 一次性 | $4/月 × 12 = $48 | $11/月 × 12 = $132 | **一次付费，永久使用** |
| Cloud Pro | $79/年 | $4/月 × 12 = $48 | $11/月 × 12 = $132 | 多设备 + 团队 + 同步 + AI Credits |
| Enterprise | $1000+/年 | Business 定制 | Team $65/月/席 | **私有部署 + 合规** |

**核心优势**：Pro 一次性 $49 对比 Smallpdf 年费 $132，**节省 63%**，且永久使用。

## 三、社区分享生态

> **v2.0 重写**：原 v1.0 为"Workflow Marketplace"（付费抽成 30% 模式）。因 AI 生态冲击，Marketplace 货币化逻辑不成立（见 [AI 生态冲击调整方案](../AI生态冲击调整方案.md) §1.1），改为**免费社区分享**模式。

### 3.1 定位转变

| 维度 | v1.0（Marketplace） | v2.0（社区分享） |
|------|---------------------|------------------|
| 核心模式 | 付费 workflow + 30% 抽成 | **免费分享 + 社区口碑** |
| 货币化 | GMV 抽成 | **不直接货币化**，通过 Cloud Pro 订阅转化 |
| 创作者激励 | 销售分成 | 信誉 + 影响力 + Cloud Pro 推荐 |
| 门槛 | 付费购买 | 免费使用，人人可下载 |
| 战略价值 | 收入来源 | **用户黏性 + SEO + 获客** |

### 3.2 社区分层

| 层级 | 内容 | 价格 |
|------|------|------|
| **Workflow** | 单个工作流（如 Shopify Images） | 免费 |
| **Template** | 配置模板（如 Instagram Post 1080x1350） | 免费 |
| **Preset Pack** | 预设包（如 Social Media Pack 6 合 1） | 免费 |
| **Workspace** | 整套工作台（如 Podcast Workspace） | 免费 |

### 3.3 创作者激励机制

社区分享不通过销售分成激励创作者，而是通过以下方式：

| 激励 | 说明 |
|------|------|
| 信誉系统 | 下载量、评分、认证创作者标识 |
| 影响力 | 创作者主页 + 作品展示 + 社区关注 |
| Cloud Pro 推荐 | 优质创作者获 Cloud Pro 免费额度 |
| 官方认证 | 认证创作者获官方推广 + 早期功能体验 |
| AI 参数优化 | 创作者 workflow 根据社区反馈自动优化建议 |

### 3.4 防复制策略

单纯 JSON 配置容易被复制，因此社区分享的价值在于**持续维护的解决方案**：

| 附加值 | 说明 |
|--------|------|
| 版本历史 | 持续更新，兼容最新 Runtime |
| 更新日志 | 透明化改进 |
| 自动升级 | 一键升级到新版本 |
| 评论评分 | 社区口碑 |
| 作者信誉 | 认证创作者 |
| 下载量 | 社会证明 |
| 官方认证 | 信任背书 |
| 配套文档 | 最佳实践 |
| AI 参数优化 | 根据输入自动调整 |

### 3.5 AI 生成 Workflow（未来方向）

```
用户："帮我把这批商品图处理成 Shopify 要求的格式"
    ↓
AI 生成 Workflow JSON（engine-ai 辅助设计）
    ↓
用户验证满意 → Save
    ↓
可选：Publish to 社区（免费分享）
    ↓
社区口碑 → 创作者信誉提升
```

**生态飞轮**：AI 生成 → 用户验证 → 社区免费沉淀 → 更多真实工作流 → AI 学习 → 更好生成 → Cloud Pro 转化。

## 四、Context Commerce（场景化商业推荐）

### 4.1 核心理念

> **不是 Banner 广告，而是工作流末端的自然推荐。**

传统广告联盟：
```
页面 → Banner → 点击 → 收入
```

Lokvis Context Commerce：
```
用户任务 → Workflow → 完成任务 → 推荐下一步需要的服务 → Affiliate 收入
```

### 4.2 推荐场景

#### 场景一：Export Destination

```
用户完成 PDF 处理
    ↓
推荐：Open in Canva / Google Drive / Dropbox / Notion
    ↓
Affiliate 收入
```

#### 场景二：Workflow Recommendation

```
用户运行 "Publish Podcast" 工作流
    ↓
推荐：Buzzsprout / Transistor / Captivate（托管平台）
    ↓
Affiliate 收入（通常 $25-100/注册）
```

#### 场景三：Creator Toolkit

```
用户访问 "How to Start a Podcast" 指南
    ↓
推荐：麦克风 / 托管 / 编辑软件 / AI 工具
    ↓
Affiliate 收入
```

#### 场景四：AI Workflow

```
用户运行 "Generate Subtitle → Translate → Voice Clone"
    ↓
推荐：ElevenLabs / HeyGen / Runway
    ↓
Affiliate 收入（通常 20-30%分成）
```

### 4.3 高价值 Affiliate 机会

| 类别 | 推荐对象 | 单次佣金 |
|------|---------|---------|
| 电商 | Shopify, Amazon Seller Tools | $50-200 |
| 播客 | Buzzsprout, Transistor | $25-100 |
| AI 工具 | ElevenLabs, HeyGen, Runway | $20-50 |
| 开发者 | Cloudflare, Vercel, Railway | $10-25 |
| 设计 | Figma, Icons, Fonts | $5-20 |
| 视频 | YouTube Premium, Vimeo | $5-15 |

### 4.4 Workflow Commerce（进阶）

```
Shopify Images Workflow
    ↓
推荐：Shopify Themes / SEO Tools / Email Tools
    ↓
Affiliate 收入
```

**收入结构**：社区 workflow 免费 + Affiliate Commission。

## 七、Open Core 商业化策略

### 7.1 开源 vs 闭源边界

#### 开源（MIT）

| 模块 | 开源原因 |
|------|---------|
| Schema | 生态标准，越多人依赖越好 |
| Runtime | 核心引擎，社区贡献 |
| SDK | 开发者采用 |
| Plugin SDK | 浏览器内嵌入兼容层 |
| MCP Server | AI 生态集成，开源促进采用 |
| CLI | 自动化场景 |
| Engine Adapters | 可替换性 |

#### 闭源（商业）

| 模块 | 闭源原因 |
|------|---------|
| Cloud Sync | 增值服务（Cloud Pro 核心） |
| Billing | 支付逻辑 |
| Team Collaboration | 企业功能 |
| Analytics | 商业智能 |
| AI Service | API 成本 |
| Enterprise Features | 高客单价 |

> **v2.0 变更**：原 v1.0 将"Marketplace"列为闭源商业核心，现已改为免费社区分享，不再属于闭源商业模块。新增 MCP Server 为开源模块（促进 AI 生态采用）。

### 7.2 开源商业化的成功参照

| 公司 | 开源 | 商业化 | 估值/收入 |
|------|------|--------|----------|
| VS Code | 编辑器 | Azure 集成 | 微软旗下 |
| GitLab | CE | EE + Cloud | $60 亿估值 |
| Supabase | 客户端 | Cloud | $20 亿估值 |
| n8n | Fair-code | Cloud + Enterprise | 5500 万欧 B 轮 |

**启示**：开源核心 + 商业云服务是验证过的模式。Lokvis 的独特之处在于**本地优先**使云服务成本极低。

## 八、商业化风险与应对

### 8.1 主要风险

| 风险 | 概率 | 应对 |
|------|------|------|
| Cloud Pro 转化率不及预期 | 中 | 强化 recurring 价值（云同步 + AI Credits），社区分享提升黏性 |
| 用户不愿为工具付费 | 中 | 一次性 Pro 降低门槛，Cloud Pro 强调便利非计算资源 |
| 企业销售周期长 | 高 | 第三年才重点投入 |
| Affiliate 收入波动 | 中 | 多元化推荐对象 |
| 开源版本被白嫖 | 低 | 商业价值在 Cloud Pro/Enterprise，非 Runtime |

> **v2.0 变更**：删除"Marketplace 冷启动失败"与"用户不愿为 Workflow 付费"风险（已取消 Marketplace 模式）。新增"Cloud Pro 转化率不及预期"风险。

### 8.2 不推荐的商业模式

| 数据售卖 | 违背隐私承诺，法律风险 |
| 流量导流（SEO 租金） | 短期收入，长期损害品牌 |
| ~~Workflow Marketplace 佣金~~ | ~~AI 生态冲击后货币化逻辑不成立~~（v2.0 删除） |

## 十、与 AI 调整方案一致性

> 本章节为 v2.0 新增，说明本章商业模型与 [AI 生态冲击调整方案](../AI生态冲击调整方案.md) 的一致性。

### 10.1 调整背景

2026 年 AI 生态发生结构性变化，对原 v1.0 商业模型形成实质性威胁：

| AI 生态变化 | 对原商业模型的影响 |
|------------|------------------|
| MCP（Model Context Protocol）成为事实标准 | 自建 Plugin SDK 生态价值被稀释 |
| Claude Skills Directory 上线（Notion/Figma/Canva 集成） | **Marketplace 货币化逻辑不成立** |
| AI Agent 自主编排能力增强 | 一次性简单任务被替代 |
| AI 直接处理文件能力增强 | 工具类搜索流量下降 |

### 10.2 商业模型调整对照

| 维度 | v1.0（原模型） | v2.0（调整后） | 调整依据 |
|------|---------------|---------------|---------|
| 核心收入 | Marketplace 佣金 35% | **Cloud Pro 订阅 40%** | Marketplace 货币化不成立，Cloud Pro 为 recurring 主力 |
| Workflow 分发 | 付费 Marketplace（30% 抽成） | **免费社区分享** | Claude Skills Directory 上线后付费 workflow 无竞争力 |
| 创作者激励 | 销售分成 | 信誉 + 影响力 + Cloud Pro 推荐 | 免费分享模式，创作者通过社区声誉获益 |
| Plugin SDK | 生态核心（P0） | 兼容层（P3，Alpha） | MCP 标准优先，Plugin SDK 降级（ADR-O2） |
| AI 定位 | 替代手动 workflow 编排 | AI 辅助设计 + 确定性执行 | 不与 AI 平台直接竞争（ADR-O3） |
| 新增收入入口 | — | MCP Server 间接驱动 Cloud Pro | MCP 集成扩大用户基数，转化为 Cloud Pro（ADR-O1） |

### 10.3 与 ADR-O1/O2/O3 的一致性

本章节商业模型与以下 ADR（均于 2026-07-13 标记为 Accepted）完全一致：

- **[ADR-O1](../adr/O1-mcp-server定位.md)**：lokvis-open 作为 MCP 能力提供方 → MCP Server 扩大用户基数，间接驱动 Cloud Pro 转化
- **[ADR-O2](../adr/O2-plugin-sdk降级.md)**：Plugin SDK 降级为兼容层 → 不依赖 Plugin SDK 生态货币化，聚焦 Cloud Pro 订阅
- **[ADR-O3](../adr/O3-engine-ai定位.md)**：engine-ai 定位为 AI 辅助 workflow 设计 → AI 辅助生成 workflow 进入社区分享生态，非付费售卖

### 10.4 Pro 门控逻辑不变

本次商业模型调整**不修改 Pro 门控逻辑**（`runtime.isPro`）。技术实现层面：

- Free 用户：基础工具 + 浏览器运行 + 社区 workflow（只读）
- Pro 用户（一次性 $49）：无限工作流 + 批处理 + 高级预设
- Cloud Pro 用户（$9/月）：Pro 所有功能 + 云同步 + 多设备 + AI Credits

Pro 门控由 `runtime.isPro` 布尔值控制，与商业模型调整解耦，无需代码变更。
