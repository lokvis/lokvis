# Lokvis 项目白皮书 · 03 产品定位与差异化

> **文档版本**：v1.0
> **发布日期**：2026-06-28
> **核心命题**：明确 Lokvis 是什么、不是什么、为什么独特

---

## 一、一句话定位

> **Lokvis is the Local-first Browser Workspace where everything runs in your browser — no uploads, no servers, no compromises.**

中文表述：

> **Lokvis 是本地优先的浏览器工作空间平台 —— 所有计算在浏览器本地完成，无上传、无服务器、无妥协。**

---

## 二、定位三要素

### 2.1 是什么（What）

| 维度 | 定义 |
|------|------|
| **产品形态** | 浏览器工作空间（Browser Workspace）+ 工作流市场（Workflow Marketplace） |
| **核心技术** | WASM + PWA + OPFS + WebCodecs + Cloudflare Edge |
| **架构模式** | Open Core（开源 Runtime + 闭源 Cloud 服务） |
| **商业模式** | 多元化：免费 + 一次性购买 + 订阅 + 企业授权 + 市场抽成 + 场景化推荐 |

### 2.2 不是什么（What Not）

| 常见误解 | Lokvis 不是 |
|---------|----------|
| "又一个 FFmpeg 在线工具" | ❌ 不是单点工具站 |
| "浏览器版 Photoshop" | ❌ 不是专业图像编辑器 |
| "浏览器版 Zapier" | ❌ 不是 API 自动化平台 |
| "在线 PDF 转换站" | ❌ 不是 iLovePDF 复制品 |
| "WASM 技术演示" | ❌ 不是 Squoosh 类 Demo |

### 2.3 为什么独特（Why Unique）

Lokvis 占据了一个**目前无人占领的市场象限**：

```
                    本地处理
                       │
                       │
         Photopea      │      Lokvis（独占象限）
         Squoosh       │      ★ 本地处理 + 工作流 + 市场
         ffmpeg.wasm   │
                       │
  单点工具 ─────────────┼───────────── 平台生态
                       │
         TinyPNG       │      n8n
         iLovePDF      │      Zapier
         Smallpdf      │      Figma
                       │      VS Code
                       │
                    云端处理
```

**核心差异化**：右上角"本地处理 + 平台生态"是市场空白。

## 三、差异化价值主张

### 3.1 对用户：四大核心价值

#### 价值一：隐私绝对保障

| 传统工具站 | Lokvis |
|-----------|-------|
| 文件上传到服务器 | **文件永不离设备** |
| 依赖企业合规承诺 | **技术层面零上传** |
| GDPR/CCPA 合规成本高 | **天然合规** |

**用户话术**：*"你的文件永远不会离开你的电脑。"*

#### 价值二：零等待、无限制

| 传统工具站 | Lokvis |
|-----------|-------|
| 上传等待（大文件分钟级） | **本地导入即时** |
| 文件大小限制（通常 100MB-5GB） | **仅受设备内存限制** |
| 并发任务限制 | **本地并行无上限** |
| 付费才能解锁大文件 | **免费即可处理任意大小** |

#### 价值三：工作流而非工具

| 传统工具站 | Lokvis |
|-----------|-------|
| 单次单工具操作 | **多步骤工作流编排** |
| 无法保存流程 | **工作流可保存、分享、复用** |
| 无批处理能力 | **原生批量处理** |
| 无场景预设 | **行业预设库（YouTube/TikTok/Shopify...）** |

**示例工作流**：
```
导入商品图 → 裁剪为正方形 → 白色背景 → 压缩为 WebP → 重命名 → 打包 ZIP
```
一键执行，可保存，可分享，可售卖。

#### 价值四：离线可用、跨平台

| 传统工具站 | Lokvis |
|-----------|-------|
| 必须联网 | **PWA 安装后离线可用** |
| 移动端体验差 | **桌面/移动端一致体验** |
| 无法持久留存 | **桌面图标，像原生 App** |

### 3.2 对开发者：三大生态价值

#### 价值一：开放的 Workflow Schema

- JSON 声明式工作流，AI/CLI/第三方都可生成
- 版本化管理，向后兼容
- 可作为"浏览器工作流运行时"的事实标准

#### 价值二：Plugin SDK

- 基于 npm 的插件分发
- 统一的能力注册机制
- 可售卖的插件市场

#### 价值三：JS SDK + CLI

- 可嵌入任意 Web 应用
- 支持 CI/CD 自动化
- 支持桌面端（Tauri/Electron）扩展

### 3.3 对企业：三大商业价值

#### 价值一：私有部署

- 本地优先架构天然适合内网
- 敏感数据不出企业网络
- 法律/医疗/金融/政府刚需

#### 价值二：SDK 授权

- 工作流引擎可嵌入企业产品
- 白标集成
- OEM 授权

#### 价值三：合规背书

- 本地处理 = 天然 GDPR/CCPA 合规
- 无需数据处理协议（DPA）
- 降低合规审计成本

## 五、产品边界与优先级

### 5.1 第一年：只做 Image Workspace

**为什么是图像？**

| 因素 | 评估 |
|------|------|
| 技术成熟度 | ★★★★★ Squoosh 开源可复用，WASM 图像处理最成熟 |
| 市场需求 | ★★★★★ 创作者/电商高频刚需 |
| SEO 机会 | ★★★★★ Task 关键词丰富（youtube thumbnail, shopify images...） |
| 实现难度 | ★★★☆☆ 中等，独立开发者可实现 |
| 商业化 | ★★★★☆ 预设库、批处理、工作流易变现 |
| 复访频率 | ★★★★★ 创作者每周多次 |

**MVP 功能清单**：
- 基础工具：Resize / Compress / Convert / Crop / Watermark
- 批处理：支持 100+ 图片同时处理
- 工作流：Linear Workflow（Load → Transform → Export）
- 预设库：YouTube/TikTok/Instagram/Shopify/Etsy 等 20+ 预设
- PWA：可安装、离线可用
- SEO：100-200 个 Task 页面

### 5.2 第二年：扩展 PDF + Video

| Workspace | 优先级 | 核心工具 | 技术基座 |
|-----------|--------|---------|---------|
| PDF Workspace | P0 | Merge/Split/Compress/OCR/Sign | pdf-lib + Tesseract.js |
| Video Workspace | P1 | Compress/Trim/Convert/GIF/Subtitle | FFmpeg.wasm |
| Audio Workspace | P2 | Trim/Normalize/Convert | FFmpeg.wasm |

### 5.3 第三年：生态化

| 方向 | 说明 |
|------|------|
| Developer Workspace | JSON/YAML/Base64/Regex/SQLite/Git |
| AI Workspace | Whisper 字幕、OCR、Caption、SAM 抠图 |
| Marketplace | 工作流市场上线，开放 UGC |
| Plugin SDK | 开发者可发布插件 |
| 企业版 | 私有部署、SDK 授权 |

### 5.4 明确不做的事

| 不做的事 | 原因 |
|---------|------|
| 完整视频编辑器 | 与 Premiere/Final Cut 竞争无意义 |
| 专业图像编辑器（PS 替代） | Photopea 已占据，无差异化 |
| 云端处理服务 | 违背 Local-first 核心定位 |
| API 按调用收费 | 与 Local-first 理念冲突 |
| 展示广告 | 破坏 PWA 体验，品牌掉价 |
| 通用 SaaS 平台 | 失去聚焦，陷入同质化 |

## 七、与竞品的差异化对照

### 7.1 vs iLovePDF

| 维度 | iLovePDF | Lokvis |
|------|---------|-------|
| 处理方式 | 云端上传 | **本地处理** |
| 隐私 | 依赖合规承诺 | **技术零上传** |
| 成本结构 | 服务器成本随流量线性增长 | **边际成本趋零** |
| 工作流 | 无 | **Linear Workflow + 市场** |
| 留存 | 一次性访问 | **PWA 安装留存** |
| SEO | 头部（2.83 亿月访问） | 长尾 Task/Workflow 关键词 |
| 价格 | $4/月起 | 免费 + 一次性 $29-79 |

**差异化策略**：不与 iLovePDF 正面竞争 PDF 工具关键词，而是主攻 Task/Workflow 长尾，以隐私+工作流+免费切入。

### 7.2 vs n8n

| 维度 | n8n | Lokvis |
|------|-----|-------|
| 处理对象 | API 连接 | **本地文件处理** |
| 用户群 | 开发者/自动化 | **创作者/设计师/电商** |
| 工作流类型 | Graph（复杂分支） | Linear（第一年） |
| 部署方式 | 自托管 | **浏览器即运行时** |
| 商业化 | 开源+企业版 | 开源+市场+企业 |

**差异化策略**：n8n 是"连接 API 的工作流平台"，Lokvis 是"连接本地工具的工作流平台"，差异化蓝海。

### 7.3 vs StackBlitz

| 维度 | StackBlitz | Lokvis |
|------|-----------|-------|
| 目标用户 | 开发者 | **创作者/设计师** |
| 核心能力 | WebContainers（Node.js） | **WASM 媒体处理** |
| 产品形态 | 在线 IDE | **生产力工作空间** |
| 商业模式 | 订阅 | **多元（市场+企业+订阅）** |

**差异化策略**：技术栈相似但场景完全不同。StackBlitz 做开发者 IDE，Lokvis 做生产力工具。

### 7.4 vs Squoosh/Photopea

| 维度 | Squoosh/Photopea | Lokvis |
|------|-----------------|-------|
| 产品形态 | 单点工具 | **平台生态** |
| 工作流 | 无 | **Linear Workflow** |
| 市场 | 无 | **工作流市场** |
| 开发者生态 | 无 | **Plugin SDK** |
| 商业化 | 免费/广告 | **多元变现** |

**差异化策略**：Squoosh/Photopea 是 Lokvis 的技术验证，Lokvis 在其基础上构建平台生态。

## 九、定位总结

### 9.1 定位声明

> **For** content creators, e-commerce sellers, and professionals **who** need to process media files frequently,
> **Lokvis is** a local-first browser workspace **that** runs all processing in your browser with zero uploads,
> **unlike** iLovePDF/Smallpdf which require uploading files to cloud servers,
> **our product** offers privacy-by-design, workflow orchestration, and a marketplace ecosystem.

### 9.2 核心三角

```
                    本地优先
                   (Local First)
                       │
                       │
                       │
              Lokvis    │
                 ┌─────┴─────┐
                 │           │
            工作流 ──── 市场生态
           (Workflow)  (Marketplace)
```

- **本地优先**：技术哲学，所有计算在浏览器
- **工作流**：产品形态，可编排、可保存、可分享
- **市场生态**：商业壁垒，UGC + 开发者 + 企业

### 9.3 一句话电梯演讲

> "Lokvis 是浏览器里的本地工具操作系统。你的文件永远不上传，所有处理在本地完成，还能把工作流保存、分享、售卖。基于开源 Runtime + 工作流市场，我们要成为浏览器工作流运行时的事实标准。"
