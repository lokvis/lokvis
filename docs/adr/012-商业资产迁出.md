# ADR-012：商业化资产迁出至 lokvis-cloud

- **状态**：Accepted
- **日期**：2026-07-02
- **来源**：PROJECT_PLAN.md §14 变更记录 v1.6/v1.7

---

## 背景

`lokvis-open` 是 MIT 许可的开源仓库，`lokvis-cloud` 是闭源商业化仓库。原 open 仓库中的 `apps/web` 包含 SEO 工具页、教程、Workspace SPA、Marketplace 等商业化资产，不适合放在 MIT 开源仓库中。

## 决策

将 open `apps/web` 中的所有商业化资产迁出至 `lokvis-cloud` `apps/web`。

### 迁出内容

| 资产 | 说明 |
|------|------|
| 50 SEO 工具页 | 基于关键词研究的工具页面 |
| 30 教程文章 | 教程内容 |
| 10 对比页面 | 竞品对比页 |
| JSON-LD / sitemap / OG 图 | SEO 基础设施 |
| Workspace SPA | React 19 工作区应用 |
| PWA 资源 | manifest.webmanifest / sw.js / offline.html / icon |
| Marketplace 相关 | 联盟广告、付费流程 |

### open 仓库 apps/ 现状

迁移后，open `apps/` 仅剩：
- `apps/docs/` — Starlight 文档站（开源文档）
- `apps/playground/` — SDK/Runtime/Plugin demo（开源示例）

### open 端 W13-16 重新分配

原 W13-16 "SEO 内容 + PWA" 整体作废，重新分配为：
- npm 包正式发版准备
- apps/playground 升级（5 个 demo）
- PWA 基础能力（仅作用于 playground）

## 理由

1. MIT 开源仓库不应包含商业化资产（SEO 页、付费流程）
2. 商业化资产属于 lokvis-cloud 闭源仓库
3. 减少 open 仓库维护范围，聚焦核心开源代码

## 后果

- `apps/web` 已从 open 仓库删除
- `.github/workflows/deploy-web.yml` 已删除
- PROJECT_PLAN 中所有 `apps/web` 引用标记 ⛔ 废弃
- cloud 仓库 `apps/web` 接管所有商业化功能
- open 端 W17 的 `17.10`（首页 AI 对比 section）和 W19 的 `19.10`（/mcp 落地页）标记废弃
